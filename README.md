# Deep Learning for Satellite Image Classification

**Project 02 — Data Science & Machine Learning Portfolio**

## Project Overview

This project explores computer vision and deep learning for satellite image classification using PyTorch.

The primary objective is to investigate how different neural-network architectures classify satellite imagery and compare their predictive performance, computational efficiency, and interpretability.

The project is developed using an NVIDIA DGX Spark GPU workstation.

## Research Question

How effectively can different deep-learning architectures classify land-use categories from satellite imagery, and how do their accuracy, computational efficiency, and interpretability compare?

## Dataset

**EuroSAT — European Satellite Land Use Classification**

The EuroSAT dataset contains approximately 27,000 labeled satellite images representing 10 land-use categories.

The project will initially utilize RGB satellite imagery and may later investigate multispectral data.

## Project Objectives

1. Understand image representation and computer vision fundamentals.
2. Explore and preprocess satellite imagery.
3. Develop a convolutional neural network from scratch.
4. Implement transfer learning using pretrained architectures.
5. Compare CNNs, ResNet, EfficientNet, and Vision Transformers.
6. Evaluate classification performance using multiple metrics.
7. Investigate model interpretability.
8. Benchmark GPU training and inference performance.
9. Develop a basic inference API.
